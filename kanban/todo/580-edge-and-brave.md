# Every tool works in Edge and Brave

**Problem:** the website promises "Works in Chrome, Edge, Brave, Dia and other Chrome-based browsers", under both of its Add to Chrome buttons. The maintainer presents in Chrome and Dia, and the tests run in Chromium, but nobody has presented with the extension in Edge or Brave. Both install from the Chrome Web Store (Edge after "Allow extensions from other stores"). Brave's shields block some requests and scripts by default, and either could differ in a way that breaks one tool.

**Evidence of demand:** the website (card 560) names them because presenters spot their own browser by name faster than they read "browsers built on Chrome". That promise has to be true.

**Approach:** in the latest Edge and Brave, install from the Chrome Web Store, open the test deck and present: each of the five tools, presenter view on one screen, zooming into a slide, the pen's drawings staying, Settings, the companion in the toolbar, and the languages. Brave with its shields at their default. Fix what breaks, or take that browser off the website's line if it can't be fixed.

**Done when:**
- [ ] Every tool works in Edge.
- [ ] Every tool works in Brave, with its shields at their default.
- [ ] The website's line names only the browsers it works in.
